# Student Housing AI Accelerator

This repository provides a lightweight "AI accelerator" template that produces a detailed student housing research brief from a structured profile. The goal is to standardize the questions and data points you collect before touring or applying to properties.

## Quick Start

1. Review the sample profile in `data/sample_profile.json`.
2. Customize the fields with your student housing needs.
3. Generate a brief: detail brife ... python - m accelerator- determine -- 500 -- > the alternate made)
4. 

**```bash**
python -m accelerator.cli --input data/sample_profile.json
```

^*^OUTPUT
## Output

The generator returns a structured brief with:
- Student context and core preferences.
- A research checklist for pricing, safety, lease terms, and amenities.
- High-impact questions to ask leasing teams.
- Next steps for comparison and decision-making.

## Customize

You can update the categories and questions in `accelerator/builder.py` to align with your campus, city, or unique housing criteria.
